# Data Management Platform

Hệ thống quản lý dữ liệu / hồ sơ hành chính: theo dõi tiến độ, cảnh báo, nhắc nhở, thống kê báo cáo và import dữ liệu.

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React 19, Vite, Tailwind CSS, Redux Toolkit, React Router |
| Backend | Python, Flask, Flask-RESTful / Blueprint |
| Database | Microsoft SQL Server (pyodbc / SQLAlchemy) |
| Charts | Recharts |
| Icons | Lucide React |
