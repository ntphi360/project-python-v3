# AGENTS.md

Mọi AI agent / Codex khi làm việc trên project này phải:

1. Đọc `skills/SKILL.md`.
2. Đọc `.codex/skills/project-core/SKILL.md`.
3. Đọc thêm skill chuyên biệt theo task:
   - Frontend React: `.codex/skills/react-feature/SKILL.md`
   - Backend Flask: `.codex/skills/flask-api/SKILL.md`
   - Database / MSSQL / Pandas / Import / Export: `.codex/skills/mssql-data/SKILL.md`
4. Thực hiện theo task user giao trực tiếp.
5. Chỉ sửa đúng phạm vi task.
6. Không tự ý thêm thư viện, thay đổi kiến trúc hoặc triển khai chức năng ngoài task.
