# Project Core Skill

## Purpose
Skill chung cho mọi task trong Data Management Platform.

## Before Starting
- Đọc `skill/SKILL.md`.
- Đọc yêu cầu hiện tại.
- Kiểm tra cấu trúc repository trước khi sửa.
- Kiểm tra code hiện có trước khi tạo code mới.
- Giữ nguyên kiến trúc hiện tại nếu task không yêu cầu thay đổi.

## Scope
- Chỉ sửa file liên quan trực tiếp đến task.
- Không tự ý thêm chức năng ngoài phạm vi.
- Không tự ý thêm thư viện.
- Không tự ý đổi tên route, component, folder hoặc file.
- Không tự ý thêm authentication, AI/ML hoặc external service.
- Không phá vỡ chức năng đã hoàn thành.

## Code Quality
- Code đơn giản, dễ đọc.
- Naming rõ nghĩa.
- Không để code/import thừa.
- Không để console.log không cần thiết.
- Ưu tiên tái sử dụng code hiện tại.
- Không tạo abstraction khi chưa cần.

## Completion
Sau khi hoàn thành:
- Kiểm tra compile/build.
- Kiểm tra import.
- Kiểm tra chức năng liên quan.
- Không để file tạm.
- Báo rõ những file đã thay đổi.
